# 采集与纠错政策

1. 仅公开职业学术信息。不要收集家庭、私人联系方式、证件、住址、个人敏感信息或未公开材料。
2. 优先学校主页、学位论文机构库、出版社元数据；每项学历、任职、关系与成果均需证据URL。
3. 共著、通讯作者、同组工作不构成师承证据；Associate Advisor 按相应学校定义，不能默认共同导师。
4. 冲突保留来源和文字说明，不通过猜测“解决”；未知不归入否定类别。
5. 只链接论文，不上传课件、答案、论文全文或未经许可的照片；避免复制整段简历原文。
6. 尊重访问限制，不绕过登录、验证码、安全警告或站点封锁；当前样板不含自动爬虫。
7. 公开仓库前先校验与人工复核。将来可通过 GitHub issue 报错，需提供人物、字段、公开证据；涉及隐私不在公开issue重贴。
8. 筛选仅用于资料导航，不给教师打分、排名或据此自动作出教育/就业决定。

## 公开教学事实

教师公开讲授或建设课程的事实独立于其本人求学经历展示。课程开设或教学年份不当作入学、授位或任职起点，也不计入教育、任职、论文或师承关系统计。每条教学事实保留直接来源，不复制课件、学生资料或考核答案。院系工作簿仍为五张表，教学摘要和来源保留在总览的资料范围说明中。
