# 历史版本与当前版本测试

旧版本来源契约保持原有固定值，不通过改写旧哈希容纳新资料。`tests/fixtures/released-1458f458.zip` 是已发布提交 `1458f4584a52a448461a5f72489efdc873305bd8` 的 410 个文件；建立时逐个与远端 Git blob 核对，测试运行时校验压缩包固定摘要。旧元数据迁移验证器要求完整 410 文件清单，所以本夹具保留完整历史输入，只用于测试，不放入 `site/`。

只有明确声称“历史版本精确字节、旧批次完整后缀、旧元数据迁移整树”的断言，显式读取 `published_root()`／`publishedRoot()`。旧来源契约、固定哈希、反例及历史验证器未改写。JS 显示兼容测试使用历史输入时，仍导入当前 `site/model.js` 和 `site/app.js`。

当前代码、规范数据、生成快照、完整 JSON Schema、来源闭包、导出、筛选、转义及导航测试仍针对实际工作树。`tests/test_current_release.py` 使用固定 612 基线与明确列出的三份独立审查增量映射（首批 NJU2、后续 NJU10、SEU10），严格核对实际全量数组与顺序、其他根字段不变；不是将真实工作树替换成夹具。已发布 614 人及 624 人历史结果，分别由 612 基线加相应固定映射独立构造，并与实际前缀核对。旧映射与其摘要不变，不为每批递归增加完整历史快照。

实际 schema、构建标识、来源安全、运行时代码守恒和全部受影响工作簿继续逐字段检验当前数据；未涉及的旧工作簿逐字节守恒，名录工作簿只允许全局人数格变化。反例覆盖旧 612 人、首批两人、后续南大十人及新批东南人物的篡改、删除、重排、重复和未知状态升格。`tests/current-release.test.js` 使用当前生成数据和当前应用代码，保留首批两人的功能断言，并检查新增十人的字段、筛选、页面展示和不提供未核实导师导航。阶段师从与非学位合作导师不视为正式论文导师认证。

运行全部测试，不跳过旧测试：

```sh
npm test
python -m unittest discover -s tests -v
python scripts/build.py
python scripts/validate_queue.py progress/work-queue.json --check-artifacts
```

历史夹具通过不等于当前版本通过。两类结果必须都通过；不能将干净历史数据当作当前候选的验证输入，也不能重新签署旧契约、略过失败断言或把来源审查当作工程验收。新增来源映射仍需独立事实复核。

`tests/current-seu-release.test.js` 使用当前生成数据及应用代码，逐人核对东南大学十人的来源字段、学校院系筛选、个人主页及未知导师展示。未因来源缺失创造师承边；攻读或访问不自动计作已授学位。

本批浏览器验收发现任职机构缺失会误用人物当前目录院系，因此仅将该显示回退改为“任职机构未核实”，并同步应用、样式及本地模块导入图的缓存标记。原任职数据不改。运行时字节守恒只允许该显示回退与六处资产引用缓存标记的精确替换，其他字节仍逐一核对；实际页面测试覆盖所有受影响的旧人物和新增医学人物，同时确认明确任职机构仍原样显示。数据构建标识不含应用代码，须同时核对应用脚本版本与代码摘要。

任职显示修正还暴露了四个旧Python测试和三个旧JS测试中遗留的历史SHA/旧版本token/1110历史HTML摘要调用点；这些精确历史断言现显式读取同一612夹具，旧摘要与历史还原器未改。JS历史1110摘要原本即运行还原的旧应用；其余actual/current渲染、CSS、安全、消费者测试继续读取真实应用。未把整套功能测试迁到旧快照。
