# 按学校保存、完整校验后展示

本次仅改变文件组织，不添加或删改人物事实，不改变搜索、学历筛选、院系、师承或Excel语义。网站需通过HTTP/HTTPS访问，不能直接双击HTML。

`data/atlas.json` 与 `site/atlas.json` 是 `academic-atlas-school-parts-v1` 清单，顶层为 `format`、`atlas`、`people_order`、`parts`。`atlas` 保留原根元信息及空 `people` 占位；该占位不是人物总数。`people_order` 保留原全库顺序。每个part列学校ID、严格相对路径、原字节SHA256、字节数、人数。`people/<school_id>.json` 保存同校人物原对象及相对顺序；data/site对应人物块相同。

Python通过 `atlas_storage.load_atlas(path)` 读取清单和实际块、验证并返回原完整业务对象。`write_atlas` 是确定性生成入口；不要直接把未校验的清单当人物数据，也不要只改清单或绕过校验。`python scripts/build.py` 仍是校验与网站/Excel构建入口。原字段未知值、来源说明、键/列表顺序保留。

浏览器先加载清单，最多4个并发请求取齐学校块，按真实响应字节校验长度、SHA256、UTF-8、学校、ID及顺序后才启用原业务路由；名录还需与数据同build。缺块、混合部署、损坏或非法路径均不显示部分统计，提示稍后刷新。SHA用于一致性校验，不是来源真实性或学位证书认证。

清单不缓存读取，块URL附内容SHA作为缓存版本键；稳定路径不承诺服务端永久不可变。部署切换时旧清单遇新块可能校验失败，刷新重新取得完整同版数据。首次仍需全量人物，不能仅据拆分声称更快或更省内存。

构建ID使用版本化、8字节长度分帧的有序输入：真实canonical清单和按清单序的真实已校验块、名录数据、构建/名录/确定性工作簿脚本及Python/JS存储加载器。网站自身build字段不参与反向输入。build版本不表示来源检索日或网站发布时间；具体检索时间仍见记录。

所有物理JSON及重组业务对象继续公开元数据、schema、安全及回归检查。旧历史fixture/pins/helpers不变；当前功能测试仍读取当前实际块。损坏路径/hash/ID/order、临时根、真实fetch和混合部署有单独负例。首次迁移的原全部304个XLSX与CSV逐字节不变，后续数据更新依旧逐批来源核验和完整回归。
