# -cn-985-academic-amatlas

中国985高校教师学术经历与师承图谱，支持学校院系浏览、学历筛选、论文链接及Excel导出

## 学术经纬 · 哈工大一校三区原型

可运行的静态原型。首期为哈尔滨工业大学一校三区的真实公开资料样板，不是完整名录，也不是教师评价或能力排行榜。

## 当前范围

- 78 个分层组织节点，保留学部、学院、系、研究院及校区待核实状态。
- 6 位样板教师，三校区各 2 位；17 条教育/联合培养经历。
- 3 条有直接证据的导师或联合培养合作指导关系。
- 4 位博士指导委员会成员独立列示，不等同于共同导师。
- 7 条论文/学位论文链接；仅链接，不复制全文。
- 5 个有样板教师的院系各一个 Excel，包含总览、经历、导师、论文、来源。

## 独立待核对名录

另保存三个学院294条官方目录记录，覆盖16类：哈尔滨电子信息165条、威海信息94条（含13条工程技术岗位）、深圳集成电路35条。35条无主页，2组同URL异名保留冲突。这些不是完整档案或已核实在职人数，不与6个详细样板自动合并。姓名链接进入明确的“个人档案尚未建立”页；仅姓名、单位与主页路径一致者标消歧候选，不作自动关联。网站有独立名录检索和Excel/CSV下载。

## 本地运行

需要 Python 3.10+ 和 openpyxl。开发测试另需 Node.js 20+。

```sh
python -m pip install -r requirements.txt
python scripts/build.py
python -m http.server 8000 --directory site
```

浏览器访问 http://localhost:8000/。不需要账户、后端或 API Key。请勿直接双击 HTML，因为数据通过 HTTP 加载。

```sh
npm test
python -m unittest discover -s tests -v
```

## 模块

- `data/atlas.json`：详细样板的数据源，公开学术事实及来源、冲突、缺项。
- `data/rosters.json`：独立待核对名录数据源，含分类覆盖和冲突；不与详细样板自动合并。
- `scripts/build_rosters.py`：生成独立名录快照与Excel/CSV，标识消歧候选而非合并人物。
- `site/`：静态 UI；个人主页和师承关系为独立路由；手机布局；可组合筛选；CSV、SVG 和 Excel 下载。
- `scripts/build.py`：校验后生成网站数据快照与院系 Excel。
- `schema/atlas.schema.json`：核心结构定义；构建另做引用、证据和循环关系检查。
- `tests/`：筛选语义、安全转义、源数据和工作簿校验。
- `docs/`：数据政策与架构说明。

## 口径

985 是按教育部历史39校名单归类，不表示就读当年已是985。中国内地、港澳台、其他国家或地区分别筛选；洲是另一独立字段。联合培养不改写学位授予院校。未收录阶段不等于没有该学位。多条经历的筛选采用任一条匹配；同时设置的地域/洲条件可能命中同阶段不同条目。

导师在职快捷导航仅对有直接任职来源且未发现冲突者提供。其他导师只显示简介与证据，绝不由“有主页”推断在职。委员会成员不计入师承边。官方页面之间存在的月份、毕业/授位时间与职称冲突保留原说明。
