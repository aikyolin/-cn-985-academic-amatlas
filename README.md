# -cn-985-academic-amatlas

中国985高校教师学术经历与师承图谱，支持学校院系浏览、学历筛选、论文链接及Excel导出

## 学术经纬 · 哈工大一校三区原型

可运行的静态原型。首期为哈尔滨工业大学一校三区的真实公开资料样板，不是完整名录，也不是教师评价或能力排行榜。

## 当前范围

- 78 个分层组织节点，保留学部、学院、系、研究院及校区待核实状态。
- 197 位分批核实详细档案，哈尔滨 159 位、威海 2 位、深圳 36 位；618 条学习经历（含非授位访问）。另有 9 条人物待完善记录，分别标明身份待核、仅姓名页或正文稀疏，不计详细档案。
- 91 条有直接证据的导师、联合培养或访问指导关系，各类型分别标明。
- 9 位博士指导委员会成员独立列示，不等同于共同导师。
- 388 条精选成果记录（含论文、学位论文、编者按与著作，类型分别标明）；部分仅由官网成果列表核证，并非每条都有逐篇可用链接，不复制全文。
- 7 个有详细档案的院系各一个 Excel，包含总览、经历、导师、论文、来源。

## 独立待核对名录

另保存 1381 条整合名录记录、1419 条原始来源观察，覆盖 16 个单位、79 个分类。记录并非唯一人数，门户列表也不等于完整现任人事名册。163 条无有效候选主页，60 组去重候选保留；8 条CMS编辑/拼接异常链接禁止导航，原值保留为待核证据。深圳004的236条多源观察依据来源记录整合为198条，明确保留整合依据；不将跨源整合称作身份去重。191 条依据官方重定向或独立官方页姓名、组织证据建立详细档案关联，其余不自动合并。威海部分来源更新时间为 2023–2024 年；计算机概况 74 名专任与可见 72 条不同口径不强补。独立名录支持检索及 Excel/CSV 下载。

## 本地运行

需要 Python 3.10+ 和 openpyxl。开发测试另需 Node.js 20+。

```sh
python -m pip install -r requirements.txt
python scripts/build.py
python -m http.server 8000 --directory site
```

浏览器访问 http://localhost:8000/。不需要账户、后端或 API Key。请勿直接双击 HTML，因为数据通过 HTTP 加载。

```sh
npm test
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

## 模块

- `data/atlas.json`：详细样板的数据源，公开学术事实及来源、冲突、缺项。
- `data/rosters.json`：独立待核对名录数据源，含分类覆盖和冲突；不与详细样板自动合并。
- `scripts/build_rosters.py`：生成独立名录快照与Excel/CSV，标识消歧候选而非合并人物。
- `site/`：静态 UI；个人主页和师承关系为独立路由；手机布局；可组合筛选；CSV、SVG 和 Excel 下载。
- `scripts/build.py`：校验后生成网站数据快照与院系 Excel。
- `schema/atlas.schema.json`：核心结构定义；构建另做引用、证据和循环关系检查。
- `tests/`：筛选语义、安全转义、源数据和工作簿校验。
- `docs/`：数据政策与架构说明。

## 口径

985 是按教育部历史39校名单归类，不表示就读当年已是985。中国内地、港澳台、其他国家或地区分别筛选；洲是另一独立字段。学历筛选仅统计 event_kind=degree 且 degree_awarded=true 的确证授位。博士学习、访问、联合培养及未知授位不计确证毕业。硕博连读按确证博士授位归类，不自动补硕士。联合培养不改写学位授予院校。未收录阶段不等于没有该学位。同一学历阶段的地域与洲条件必须命中同一条确证授位记录，不将两条经历拼成一次匹配。

导师在职快捷导航仅对有直接任职来源且未发现冲突者提供。其他导师只显示简介与证据，绝不由“有主页”推断在职。委员会成员不计入师承边。官方页面之间存在的月份、毕业/授位时间与职称冲突保留原说明。
